# SSBJ 開示レポート R1 の対象範囲（T01 合意事項）

SSBJ 開示レポート（試行版 R1）について、対象利用者・利用場面・対象範囲・初回対象の要求項目・入力例と出力例を
合意した内容をまとめる。データ契約と保存の仕組みは [`ssbj-spec.md`](ssbj-spec.md) を正とし、この文書は
「R1 で何を扱うか」を正とする。§12（仮置き）の確定内容もここを参照する。

> 基準の本文は転載しない。要求は項番号と、この文書の言葉による要約で示す（`ssbj-spec.md` §1）。
> 項番号は下の「参照する基準」の版で確認したものに限る。

---

## 1. 位置づけ

- R1 は**社内確認用の試行版**であり、SSBJ 基準への準拠の認定、第三者保証、対外提出の完了を意味しない。
- 画面・レポートの構成は SSBJ 基準と有価証券報告書のサステナビリティ開示に沿わせる。ただし、基準のすべての定めに
  従っていない限り「準拠している」と記述できない（適用基準 第79項）。R1 は OGT の算定機能の制約（§3.3）により
  すべての定めを満たせないため、画面・出力の「準拠や提出完了を保証しない」注記は外さない。

## 2. 対象利用者と利用場面

| 項目 | 内容 |
|---|---|
| 対象利用者 | 中小企業の GX 担当者 |
| 利用場面 | 親会社（上場企業）が有価証券報告書で SSBJ 基準に従った開示を行うにあたり、子会社・関連会社の分の情報を求められたときに、その下地となるレポートを作成して提出する |
| 提出先 | 親会社。親会社はこのシステムの利用者ではなく、出力したファイルを受け取る |

この利用場面から、R1 のレポートには次の性質が求められる。

- 子会社・関連会社の排出量は、親会社の連結の開示に合算される（スコープ 1・2 は連結会計グループとその他の投資先に
  分けて開示され、集計範囲は親会社が選ぶ測定アプローチで決まる。気候基準 第52項・第60項）。
- リスク・機会、ガバナンス、リスク管理の情報は、親会社の開示に統合される。そのため四本柱（ガバナンス・戦略・
  リスク管理・指標及び目標）の構成で持つ。

新しいライブラリを追加せずに作れる。

### 3.2 対象外

- レビュー・承認ロック、差分画面
- 文章・判断の自動生成、自動の準拠判定・重要性判断
- 初回対象の外にある要求（§5.2 の △）。SSBJ 基準のすべての入力欄は扱わない
- 業種に応じた要求項目の出し分け（§6 の参照は行う）
- 拠点別の集計（組織全体のみ）

### 3.3 OGT の算定機能に従う（OGT 本体は変更しない）

排出量は OGT の算定機能のとおりに扱う。基準との差は出力に注記して示す。

| 項目 | 基準 | R1（OGT） |
|---|---|---|
| 対象ガス | 京都議定書の 7 種類を CO2 相当に集約（気候基準 第4項(6)・第65項） | 公式係数は実質 CO2 のみ |
| スコープ 2 | ロケーション基準は必須、マーケット基準は契約証書の情報の代わりに使える（第53項・第54項）。温対法 SHK 制度の方法を用いる場合の対応は実務対応基準第1号 第7項 | 基準は区別せず「基準不明」とし、係数の種類（基礎 / 調整後 / 区分なし）ごとの内訳を添える（`ssbj-spec.md` §7.2） |
| GWP | 最新の IPCC 評価の 100 年値（第66項・第68項） | 既定は AR6（`functional-spec.md` §7.2） |
| スコープ 3 | 関連するカテゴリー別（第55項） | カテゴリー別あり（方式別の採用値） |

親会社の開示ではロケーション基準のスコープ 2 が必須のため、R1 の出力はその値を含まないことを明示する。

## 6. 産業別ガイダンス

気候基準は、リスク・機会の識別と開示の作成にあたり、IFRS S2 号の付属ガイダンス「産業別ガイダンス」の開示
トピックと産業別の指標を参照し、適用できるかを検討するよう求めている（第16項・第17項・第86項）。
適用基準も SASB スタンダードの開示トピックの参照を求めている（第41項）。産業別ガイダンスは SASB の産業分類
（SICS。11 セクター・68 産業）で構成されている。

R1 では、業種ごとに要求項目を出し分けない。レポートの基本情報に業種（SICS コード）を記録し、詳細画面に
該当する巻へのリンクを示す（一覧は `src/features/ssbj/utils/sicsIndustries.ts`）。本文は転記せず、リンクで参照する。

単体テストの架空データ（`src/features/ssbj/__fixtures__/fictionalReport.ts`。架空サンプル株式会社）は同じ内容の

| 区分 | 入力例 |

### 7.2 出力例（Excel・PDF・CSV に共通の構成）

プレビュー・Excel・PDF・CSV は、保存版（`ssbj_report_versions`）から作り、OGT の最新値を再取得しない。

1. 表紙・基本情報（レポート名、報告企業、提出先の親会社と関係・持分比率、測定アプローチ、業種、対象年度と期間、版番号と保存日時、社内確認用であることの注記）
2. ガバナンス
3. 戦略（リスク・機会の一覧と時間軸の定義を含む）
4. リスク管理
5. 指標及び目標（スコープ 1・2・3、カテゴリー別、目標）
6. 注記

**表示の規則**

- 未入力・未確認・非該当は状態の名称で表示し、0・空欄・「なし」にしない。入力済みの 0 は 0 と表示する。
- 内部メモは開示の欄に出さない。出す場合は別の列・欄にして「内部」と明示する。

**CSV の列（案）**

| 列 | 例 |
|---|---|
| 版番号 / 保存日時 | 3 / 2025-06-03 12:00 |
| 章 | 戦略 |
| 項目 | リスク・機会 |
| 要求（項番号） | 気候 19(1)(2)(3) |
| 状態 | 入力済み |
| 開示内容 | 炭素価格の導入による調達コストの上昇（移行リスク・中期） |
| 数値 / 単位 | （排出量の行のみ） |
| 注記 | （算定の充足状態など） |
| 内部メモ（開示しない） | 影響額の試算は経営企画部で実施中（架空） |

**必ず載せる注記**

- 社内確認用の試行版であり、SSBJ 基準への準拠や提出の完了を保証しない。
- 排出量は OGT の算定値で、対象ガスは実質 CO2 のみ（7 種類を集約していない）。
- スコープ 2 はロケーション基準 / マーケット基準を区別していない（係数の種類ごとの内訳を添える）。
  ロケーション基準のスコープ 2 は含まない。
- 「算定済み」は登録済みのデータがすべて算定済みという意味で、網羅していることを意味しない。
- サプライヤー別の実排出量は参考値で、合計に含めない。
